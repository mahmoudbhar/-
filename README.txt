تعليمات التعديل والتحديث:
=========================
1. إضافة صورة خاصة بك بدلاً من الرابط الأونلاين:
   - أنشئ مجلداً جديداً داخل المجلد وسمّه: images
   - ضع صورتك بداخله واسمّها مثلاً: profile.jpg
   - افتح ملف index.html وابحث عن السطر:
     <img src="https://alsabreen.gitlab.io/images/mohamedramzey.jpg" ...
   - غيّره إلى:
     <img src="images/profile.jpg" ...

2. تغيير الاسم أو النصوص:
   - افتح ملف index.html بأي محرر نصوص (مثل Notepad أو VS Code).
   - ابحث عن اسم "محمد رمزي أبو حصيرة" وغيّره إلى أي اسم تريد.

3. رفع المجلد على GitHub Pages:
   - قم بفك الضغط عن المجلد وعرض الملفات.
   - ارفع جميع الملفات بنفس الترتيب في مستودع GitHub الخاص بك.
